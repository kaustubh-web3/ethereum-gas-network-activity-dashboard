# Ethereum Gas & Network Activity Dashboard

A Dune Analytics dashboard analyzing Ethereum gas usage and network activity using SQL and blockchain data.

---

## Business Question

How has Ethereum network activity changed over the last 30 days, and what trends can be observed in gas usage, transaction volume, active addresses, and overall network utilization?

---

## Dashboard Metrics

- Daily Gas Used
- Average Gas Price
- Daily Ethereum Transactions
- Daily Active Addresses
- Average Block Size
- Average Gas Used Per Block

---

## Key Insights

- Ethereum gas usage remained relatively stable during the last 30 days.
- Average gas prices fluctuated based on network demand.
- Ethereum consistently processed millions of transactions each day.
- Daily active addresses remained stable, indicating healthy user activity.
- Average block size showed only minor variation.
- Average gas used per block remained consistent, reflecting stable network utilization.
